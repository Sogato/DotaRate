## Назначение

Backend отвечает за мониторинг профессиональных матчей в реальном времени и генерацию прогнозов по ним. В отличие от ML-модуля, который работает офлайн (сбор данных и обучение), backend работает в режиме реального времени.

## Связь с другими модулями

- **ML-модуль → Backend.** Связь односторонняя и офлайновая: backend **не обращается** к ML-модулю в рантайме. Вместо этого в него переносятся **копии обученных моделей** — ансамбли `.keras`, формат которых описан в [`ml.md`](ml.md) (стадия 6). Регрессионные модели (`score`/`time`) самодостаточны: денормализация встроена внутрь, и дополнительных файлов рядом с моделями не требуется.
- **`dota_core` → Backend.** При инференсе backend будет опираться на общий пакет `dota_core` (см. [`shared.md`](shared.md)): `HeroMapper` для тех же плотных индексов героев, что и при обучении, и общий config. Это удерживает индексы героев консистентными между обучением и предсказанием — собственно, ради этого общий код и вынесен из ML-модуля.
- **Backend → Telegram Bot.** Бот публикует данные, которые предоставляет backend. См. [`bot.md`](bot.md).

## Планируемые зоны ответственности

- Отслеживание проф. live-матчей через интеграцию с внешними API
- Парсинг коэффициентов букмекеров
- Генерация прогнозов на активные матчи через локальные копии моделей из ML-модуля
- Сохранение информации о матчах, командах и результатах в БД
- Обновление статусов матчей и финальных результатов в БД
- Предоставление данных клиентскому интерфейсу через API
