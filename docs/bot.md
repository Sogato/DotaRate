## Назначение

Telegram Bot — пользовательский интерфейс системы. Это тонкий слой публикации: он берёт данные у backend и выкладывает их в Telegram. Собственной логики прогнозирования или сбора данных у бота нет.

## Связь с другими модулями

- **Backend → Telegram Bot.** Бот получает данные о матчах и прогнозах от backend и только отображает их. См. [`backend.md`](backend.md).

## Планируемые зоны ответственности

- Формирование и публикация сообщений о live-матчах с прогнозом
- Обновление сообщений по мере изменения данных матча в реальном времени
- Публикация статистики с визуализацией результатов (графики, сводки)
